Attention as Statistical Geometry

Before neural interpretations: attention is matrix decomposition, covariance structure, and variance routing. This tab shows how transformer attention relates to classical statistical operations like PCA, SVD, and correlation analysis.

The Covariance Connection

Matrix Structure

Q·KT computes pairwise similarities—essentially a gram matrix.

If Q and K were centered (mean=0), this would be a covariance matrix:
Cov(Q,K) = (1/N) Q·KT

Transformer attention skips centering and scaling, but the geometric intuition remains: high similarity = shared variance direction.

💡 Key insight: Attention weights identify which token-pairs vary together in the projected space.

Singular Value Decomposition (SVD) View

  

    

      
How SVD Relates

      

        We can decompose Q·KT as:
        

        Q·KT = U Σ VT
        


        • U: Left singular vectors (query space structure)

        • Σ: Singular values (strength of each component)

        • VT: Right singular vectors (key space structure)
        


        Attention is low-rank if Σ has few large values.
        This means information flows through a small number of "channels."

Correlation vs. Attention

  

    

      
Pearson Correlation Matrix

      

      

        Normalized similarity: correlation ∈ [-1, 1]
      

    

    

      
Attention Matrix (Softmax)

      

      

        Row-normalized, non-negative: weights ∈ [0, 1], row sum = 1
      

    

  

  

    
Why Softmax Instead of Correlation?

    
    
      
  • Positivity: Softmax guarantees non-negative weights (interpretable as "routing strength")
    • 
      
  • Normalization: Row sums = 1 means each output is a convex combination of values
    • 
      
  • Temperature: Softmax temperature controls peakiness; correlation has no such tuning
    • 
      
  • Differentiability: Smooth gradients for backprop (unlike hard max or threshold operations)
    • 
    

  






  
Other Statistical Perspectives

  

    

      
Kernel Methods

      

        Q·KT is a kernel gram matrix with kernel k(q,k) = q·k.
        


        Other kernels (RBF, polynomial) would change the similarity metric.
        Some attention variants explore this (e.g., cosine attention, ReLU attention).
      

    

    

      
Fisher Information

      

        Attention can be seen as a second-moment matrix (like Fisher information).
        


        High attention = high "information" about that token.
        This connects to optimal transport and information geometry.
      

    

    

      
Markov Chains

      

        Since rows sum to 1, attention is a stochastic matrix (transition probabilities).
        


        Multi-head attention with residuals is like mixing multiple Markov processes.
      

    

  






  
Summary: Variance Accountability

  

    When designing attention variants, always check:
  

  
    
    
  1. Rank: Is your attention full-rank or low-rank? Low-rank loses variance.
    2. 
    
  2. Eigenvalue distribution: Are a few modes dominant, or is variance spread evenly?
    3. 
    
  3. Cumulative variance explained: What % of variance do the top-k components capture?
    4. 
    
  4. Reconstruction error: If you threshold/sparsify attention, how much signal is lost?
