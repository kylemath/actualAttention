RNN vs LSTM vs Transformer: Mathematical Foundations

How do these architectures differ mathematically? We express each as an operation on input X, revealing where the transformer's covariance-like computation (Q·KT) fundamentally diverges from sequential models. The key insight: transformers compute explicit pairwise relationships; RNN/LSTM compress history into a fixed-size state.

1. RNN: Sequential Compression (No Explicit Covariance)

Operation on X = [x₁, x₂, ..., xₙ]

// Initialize hidden state
h₀ = 0

// Recursive update for each timestep t:
hₜ = σ(Wxh·xₜ + Whh·hₜ₋₁ + b)

// Output at final timestep:
y = Why·hₙ

Unrolled as Single Operation

// Nested composition:
hₙ = σ(Wxh·xₙ + Whh·σ(Wxh·xₙ₋₁ + Whh·σ(...)))

// Or equivalently:
hₙ = f(xₙ, f(xₙ₋₁, f(xₙ₋₂, ...f(x₁, h₀))))

Statistical Equivalent

Autoregressive State-Space Model

The hidden state hₜ is a lossy compression of all past inputs—like computing a running sufficient statistic.

Key Properties:

  • No pairwise computation: Each timestep only "sees" compressed history
  • Fixed bottleneck: All past info squeezed into h ∈ ℝd
  • Markov property: hₜ is sufficient statistic for past given model
  • Similar to: Kalman filter, exponential smoothing
⚠️ Information Loss:

Information about x₁ at timestep N is exponentially decayed:
Info(x₁ → xₙ) ≈ WhhN-1 · x₁

2. LSTM: Gated Selective Memory (Adaptive Variance Retention)

Operation on X = [x₁, x₂, ..., xₙ]

// For each timestep t:

// Forget gate (what to discard):
fₜ = σ(Wf·[hₜ₋₁, xₜ] + bf)

// Input gate (what to add):
iₜ = σ(Wi·[hₜ₋₁, xₜ] + bi)

// Candidate cell state:
c̃ₜ = tanh(Wc·[hₜ₋₁, xₜ] + bc)

// Cell state update (the "highway"):
cₜ = fₜ ⊙ cₜ₋₁ + iₜ ⊙ c̃ₜ

// Output gate:
oₜ = σ(Wo·[hₜ₋₁, xₜ] + bo)

// Hidden state:
hₜ = oₜ ⊙ tanh(cₜ)

Statistical Equivalent

Exponential Smoothing with Adaptive Forgetting

The cell state is a weighted running average where weights are learned per timestep: 

cₜ ≈ Σₛ (Πᵤ₌ₛ₊₁ᵗ fᵤ) · (iₛ ⊙ c̃ₛ)

Gate Interpretations:

  • fₜ (forget): Variance decay rate—how much past signal to retain
  • iₜ (input): Variance injection—how much new signal to add
  • oₜ (output): Information gating—what to expose to next layer
  • cₜ (cell): Long-term memory "highway" for gradient flow
Still No Pairwise Computation:

LSTM decides how much of each past timestep to "remember" but never directly compares token t with token t-5. Information flows only through the cell state highway.

3. Transformer: Explicit Pairwise Covariance

Operation on X ∈ ℝN×d

// Linear projections:
Q = X WQ    // Queries: ℝN×dk
K = X WK    // Keys: ℝN×dk
V = X WV    // Values: ℝN×dv

// THE KEY OPERATION - Gram/Covariance Matrix:
S = Q KT / √dk    // ℝN×N pairwise similarities

// Softmax normalization:
A = softmax(S)    // Row-stochastic attention weights

// Weighted aggregation + residual:
Z = A V + X       // Output: ℝN×dv
🔑 The Covariance Connection:

S = QKT is a Gram matrix (pairwise inner products in projected space).

If Q, K were mean-centered: Cov(Q,K) = (1/N) QKT

This computes all N² pairwise relationships simultaneously.

Statistical Equivalent

Kernel Regression / Nadaraya-Watson Estimator

Each output is a weighted combination of all values, with weights determined by query-key similarity: 

zᵢ = Σⱼ K(qᵢ, kⱼ) · vⱼ / Σⱼ K(qᵢ, kⱼ)

where K(q,k) = exp(q·k / √d)

Why This Changes Everything:

  • Direct access: Token i can "query" any token j directly
  • Parallel: All N² similarities computed simultaneously
  • No compression: Information preserved, not squeezed through bottleneck
  • Learned similarity: WQ, WK adapt the metric to the task

Complete Training Operation Comparison

RNN Training (BPTT)

// Forward:
∀t ∈ [1,N]:
  hₜ = tanh(Wxhxₜ + Whhhₜ₋₁)

Loss = ℒ(hₙ, y)

// Backward (BPTT):
∂ℒ/∂Whh = Σₜ (∂ℒ/∂hₜ · ∂hₜ/∂Whh)

// Gradient through time:
∂hₙ/∂hₜ = Πₛ₌ₜᴺ WhhT·diag(1-hₛ²)
Vanishing Gradient: Repeated multiplication by Whh causes exponential decay.

LSTM Training

// Forward:
∀t:
  [fₜ,iₜ,oₜ,c̃ₜ] = gates(Wxxₜ + Whhₜ₋₁)
  cₜ = fₜ⊙cₜ₋₁ + iₜ⊙c̃ₜ
  hₜ = oₜ⊙tanh(cₜ)

// Backward (cell highway):
∂ℒ/∂cₜ = ∂ℒ/∂cₜ₊₁·fₜ₊₁ 
       + ∂ℒ/∂hₜ·oₜ·(1-tanh²cₜ)

// Gradient flows through f gates
Cell Highway: cₜ = fₜ⊙cₜ₋₁ allows gradient to flow with less decay, but still sequential.

Transformer Training

// Forward:
Q,K,V = XWQ, XWK, XWV
S = QKT/√d  // Gram matrix
A = softmax(S)
Z = AV + X    // Residual

// Backward (parallel!):
∂ℒ/∂WQ = XT·(∂ℒ/∂S)·K

// All N² gradients at once
∂ℒ/∂S = ∂ℒ/∂A · A · (I - 1·AT)
No Sequential Dependence: Every gradient flows through the full covariance matrix in one step.

The Covariance as "Memory Access Pattern"

RNN/LSTM: Compressed Access

x₁ → x₂ → x₃ → x₄ → x₅
Information flows only through chain. Each step compresses. 
Info(xᵢ → xⱼ) ≈ Whhj-i · xᵢ

// Exponentially decayed!
// After 10 steps: ~0.1^10 = 10^-10

Transformer: Direct Query Access

x₁ x₂ x₃ x₄ x₅
↕ ↕ ↕ ↕ ↕ (all connected to all)
Every token can directly attend to every other token. 
Info(xᵢ → xⱼ) = Aⱼᵢ · vᵢ = softmax(qⱼ·kᵢT) · vᵢ

// Direct query!
// "How much does j want to read from i?"
💡 The Key Insight:

The attention weight Aji is literally "how much does position j want to read from position i"—computed via their covariance in the projected space (qj·ki). This is why transformers can capture long-range dependencies that RNNs struggle with: there's no information decay, just direct similarity lookup.

Summary: Why Covariance Matters

What RNN/LSTM Compute:

output = f(compress(X))

// Where compress() is:
h = recursive_fold(x₁, x₂, ..., xₙ)

// Statistical view:
h ≈ E[X | past] + noise
// Lossy! Fixed-size summary.

What Transformers Compute:

output = f(Cov(X) · X)

// Where Cov() is:
S = X·W·WT·XT  // N×N

// Statistical view:
zᵢ = Σⱼ Cov(qᵢ, kⱼ) · vⱼ
// Lossless! Full pairwise structure.

The Tradeoff:

  • RNN/LSTM: O(N) memory, O(N) compute—but lossy compression and sequential training
  • Transformer: O(N²) memory, O(N²) compute—but lossless pairwise relationships and parallel training
  • The bet: Quadratic cost is worth it for capturing the full covariance structure of the sequence
🎯 This explains transformer success: Language and many other domains have complex long-range dependencies. The explicit covariance computation lets transformers capture these directly, while RNN/LSTM must hope their compressed state preserves the relevant information through many steps of decay.
