Why "attention" is a misnomer

Transformer attention is a weighted routing operator. It does not necessarily reflect sensory selection or endogenous control. Use this tab to explore how simple scores, softmax temperature, and input structure drive the routing.

Transformer Attention: Architecture Flow

Component Legend

📥 Input (X): Token embeddings (N×d matrix)
🔄 Q, K, V: Linear projections WQX, WKX, WVX
✖️ Scores: QKT / √dk (scaled dot product)
📊 Softmax: exp(scores/τ) / Σ (temperature τ)
⚖️ Attention: Normalized weights (row sums = 1)
📤 Output (Z): Attention × V (weighted sum)
💡 Key insight: This is routing, not selection. Every output token is a weighted mixture of all value vectors, determined by query-key similarity. No winner-take-all, no inhibition—just soft blending.
Dimensions: N tokens, d dimensions per token, dk key/query dim.
